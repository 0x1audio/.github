# Getting help

Thanks for building with Mixel. Here's where to go, and when to expect an answer. Times are working days in Italy, where we are.

| You have | Go to | First reply |
| --- | --- | --- |
| A question about building an app, a page, a script or an MCP setup | [Discussions › Q&A](https://github.com/orgs/0x1audio/discussions/categories/q-a) | Within 3 working days |
| A bug in an official app, the SDK, the `mixel` command or the template | An issue on that repository | Within 3 working days |
| A pull request | The repository | A first review within 5 working days |
| An app waiting for review | `mixel status` shows where it is and any notes | A decision or notes within 5 working days of sending it |
| Something you made | [Discussions › Show and tell](https://github.com/orgs/0x1audio/discussions/categories/show-and-tell) | We read every one |
| A security problem | Privately, never in public: [0x1audio.com/security](https://0x1audio.com/security) | Within 3 working days, as SECURITY.md says |
| Something in Mixel itself, your account or Plus | In Mixel, **Help › Send Feedback…**, or [support@0x1audio.com](mailto:support@0x1audio.com) | As the [help page](https://0x1audio.com/help) says |

Mixel itself isn't developed in these repositories, so a report about the Mixel app here gets moved to the right place.

Before you ask, these often have the answer:

- [The developer docs](https://docs.0x1audio.com/start), with every error code and its fix on [Errors](https://docs.0x1audio.com/errors).
- `mixel doctor`, which checks your setup and prints the fix for anything missing.
- The four official apps, which are built with the same SDK as yours: [Audio Converter](https://github.com/0x1audio/0x1audio-converter-app) is the place to start.
