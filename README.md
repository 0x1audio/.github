# 0x1audio/.github

The shared community files for 0x1audio's public repositories, and the home of the organization's Discussions.

- `profile/README.md` is the page at [github.com/0x1audio](https://github.com/0x1audio).
- `.github/` holds the default issue forms and pull request template for repositories without their own, and the forms for Discussions.
- [SUPPORT.md](SUPPORT.md) says where to ask and when to expect an answer.
- [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md) is the Contributor Covenant 2.1, for every repository and for Discussions.

Mixel itself isn't developed here. For something in Mixel, choose **Help › Send Feedback…** in the app, or see [0x1audio.com/help](https://0x1audio.com/help). To report a security problem privately, see [0x1audio.com/security](https://0x1audio.com/security).
